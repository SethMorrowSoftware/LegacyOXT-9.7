# family has a supplement next to this file (engine-tests-baseline-windows.txt,
# -linux.txt, -mac.txt) with the tests that fail only there.
#
# The failures are recorded, not fixed: this repository keeps Tom Perry's
# code as it is, so a line here is a bug or a limitation of that code (or of

# made there. Say which in a comment above it.
#
# One "<suite>: <test>" per line, as the check names failures; "? " before
# it marks a test that fails only sometimes (its passing is not reported);
# text after " #" is a comment. Remove a line when its test passes: the
# check lists the baseline entries that did.
